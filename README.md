# Rapp Collections — Order form

Simple standalone order form (project → rooms → bedding + fills + notes).

## Run

```bash
cd assets/order-form
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

## Features

- Project name + project notes
- Add / rename / remove rooms
- Per room: bed size + qty, pillow cases, fitted sheet, duvet (base color + multi thread colors), fill options, protectors, room notes
- Color & thread chart browser
- Auto-saves to browser localStorage

## Stack

Vite + React + TypeScript. No backend in v1.
